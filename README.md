# NoFences

NoFences 是一个开源、轻量的 Windows 桌面图标整理与分区工具。它基于原生 WinForms 与 Windows Shell 深度开发，在桌面上提供可自由移动、自由缩放、支持毛玻璃特效与现代化主题的桌面图标分区面板。

分区窗口直接附着于 Windows 桌面底层（`Progman` / `WorkerW`），在使用 `Win + D` 返回桌面或切换窗口时始终稳固留在桌面上，不影响系统桌面正常操作。

## 🌟 核心功能特性

### 1. 桌面整理与快捷方式智能托管
- **拖拽添加**：直接将桌面或文件资源管理器中的文件、文件夹拖入分区即可收纳。
- **快捷方式智能托管**：将桌面根目录的 `.lnk`、`.url`、`.website` 拖入分区时，NoFences 会自动托管并隐藏原生桌面图标；当移除图标、正常退出程序或卸载时，会自动恢复到原桌面上并尝试还原原网格位置。
- **引用保护**：普通磁盘文件与文件夹拖入时仅保存路径引用，绝不随意移动或删除源文件。

### 2. 原生桌面级图标度量与文字自适应展开
- **动态图标度量**：实时捕获 Windows 桌面视图实际图标尺寸与间距（支持响应 `Ctrl + 鼠标滚轮` 的桌面图标缩放）。
- **智能文案省略与展开**：
  - **未选中状态**：图标名称最多显示两行，超出部分显示省略号（`...`），保持桌面整洁一致。
  - **选中状态**：单击图标选中后，超出两行的长文件名会自动向下完整展开，方便查看超长文件名，点击空白处即可收起。
- **高清字体渲染**：原生支持本地化桌面字体（如微软雅黑 `Microsoft YaHei UI`），像素级网格拟合对齐与整像素投影，字形清晰锐利无重影。
- **高质量图像插值**：采用双三次（Bicubic）平滑插值算法渲染缩略图与缩放图标，杜绝锯齿与模糊。

### 3. 图标与文字自由缩放微调 (10% ~ 200%)
- 提供无级缩放滑块，可在系统默认图标大小基础上进行 **10% ~ 200%** 的微调。
- 支持单步增减按钮、数值直接输入以及 **25% / 50% / 75% / 100%** 常用预设一键切换与重置。

### 4. 自动折叠（鼠标悬停展开）
- 支持将分区设置为“自动折叠”。
- 开启后，鼠标移开时分区自动收缩为仅剩一条标题栏；当鼠标移入时自动平滑展开全部内容，极大节省桌面空间。

### 5. 双重右键菜单无缝集成
- **图标右键**：在分区内右键点击任意条目，直接唤起 Windows 原生文件上下文菜单（支持“打开方式”、“剪切”、“复制”、“属性”等原生 Shell 操作）。
- **管理菜单**：在分区空白区域右键，或按住 `Shift + 右键` 点击任意条目，唤起 NoFences 应用管理菜单。

### 6. 图标多选批量管理
- 提供专门的“管理图标”多选移除模式。
- 在此模式下点击各个图标可批量勾选，并在底部确认栏一键移除，被托管的原生桌面快捷方式会安全恢复到桌面上。

### 7. 现代化 Fluent 主题与深色模式
- **预置主题**：
  - **默认主题**：经典半透明黑底栅栏。
  - **Windows 11**：现代 WinUI Fluent 风格，圆角、微边框与高质感卡片布局。
  - **Windows XP**：Luna 经典复古风格。
  - **自定义主题**：完全开放所有外观与色彩参数配置。
- **独立黑暗模式**：支持一键切换全局深色/浅色模式，与主题风格独立生效。
- **全方位视觉个性化**：
  - 自由调节圆角半径（0 ~ 48 px）、主面板不透明度与标题栏不透明度。
  - 支持 Windows 10/11 系统的背景毛玻璃模糊（Acrylic / Aero Blur）。
  - 支持自定义分区背景图片（填充、适应、拉伸、居中、平铺布局与透明度调节）。
  - 18 种详细颜色变量自定义。
  - 内置现代选项组件：圆角下拉框（带左侧强调色指示条）、圆角数值步进框、胶囊标签页。

### 8. 多显示器与高分屏适配
- 完整支持 Per-Monitor V2 DPI 动态感知，在不同缩放比例的高分屏之间拖拽时，界面与文字均能清晰自适应缩放。

## 📖 使用指南

### 基础操作

| 操作 | 交互方式 | 说明 |
| :--- | :--- | :--- |
| **添加图标** | 拖拽文件/文件夹进入分区 | 将桌面快捷方式或任意文件直接拖进栅栏内 |
| **打开文件/程序** | 双击图标 | 启动对应程序、打开文件或文件夹 |
| **选中条目/展开文字** | 单击图标 | 选中该图标；若文件名超过 2 行将自动展开显示全部文本 |
| **取消选中** | 单击空白区域 | 取消当前图标的选中状态，展开的文字恢复截断 |
| **移动分区** | 鼠标拖拽标题栏 | 按住标题栏即可在桌面任意拖动分区位置 |
| **调整分区大小** | 拖动边缘或四角 | 鼠标移到分区边缘或四角（10px 热区）呈现调节光标后按住拖动 |
| **滚动浏览内容** | 鼠标滚轮 | 当分区内图标超过窗口容量时，在分区内滚动滚轮即可上下翻滚 |
| **双击标题栏折叠/展开** | 双击标题栏 | 快速收起或展开分区高度 |

### 右键菜单说明

#### 1. 条目原生菜单 (Windows Shell)
- **直接右键点击条目**：直接调用 Windows 原生右键菜单，支持 Windows 系统的完整文件命令。

#### 2. 分区管理菜单 (NoFences)
- **打开方式**：在分区空白区域右键，或按住 **`Shift` + 右键点击任意条目**。
- **菜单功能列表**：
  - **管理图标...**：进入图标多选移除模式。点击图标进行多选，底部栏显示已选数量，点击“移除选中项”可批量恢复/移出分区，点击“取消”退出管理模式。
  - **锁定**：勾选后禁止拖拽移动和调整大小，防止日常误触改变桌面布局。
  - **自动折叠**：勾选后鼠标离开时自动收缩为标题栏，鼠标移入时展开。
  - **重命名...**：修改当前分区的标题名称。
  - **标题栏高度...**：调节标题栏高度（20 ~ 100 逻辑像素），自动匹配标题字体大小。
  - **缩放比例**：
    - 呼出带有滑块、微调步进按钮、快捷百分比（25% / 50% / 75% / 100%）与重置按钮的面板，自由调整分区内图标与文字的大小。
  - **主题风格...**：打开全局主题风格设置中心。
  - **黑暗模式**：全局深色模式快捷开关。
  - **新建桌面分区**：在桌面上快速创建一个全新的空白栅栏。
  - **关闭此栅栏**：关闭当前分区（分区数据仍保留在磁盘上）。
  - **移除栅栏**：彻底删除当前栅栏（其中托管的桌面快捷方式会自动安全释放并放回桌面）。
  - **退出 NoFences**：安全退出程序，所有托管中的桌面图标会自动恢复至桌面。

### 主题配置面板使用

在管理菜单中点击 **“主题风格...”** 可打开配置中心：
1. **主题选择**：在顶部下拉框中切换“默认”、“Windows 11”、“Windows XP”或“自定义”。
2. **基于此主题自定义**：选中某个预置主题后点击此按钮，可将该预置主题的全部外观与色彩复制到“自定义”中继续微调。
3. **外观选项卡**：
   - 修改字体名称、右键菜单风格（标准/Win11/XP）。
   - 调节圆角半径、主面板不透明度与标题栏不透明度。
   - 勾选“启用背景模糊”（在透明栅栏后启用 Windows 系统级毛玻璃效果）。
4. **颜色选项卡**：
   - 提供 18 项色彩拾取器，精确自定义面板、标题、文字、悬停、选中、边框、菜单各状态的颜色。
5. **背景图片选项卡**：
   - 支持为分区添加个性化背景图，支持填充、适应、拉伸、平铺、居中等排布方式并可调节图片不透明度。
6. **实时预览**：设置中心上方实时显示分区外观与菜单效果，点击“应用”即可在桌面上实时生效。

## 🛡️ 数据安全与故障恢复

### 存储路径
所有配置与托管数据统一保存在当前用户的应用数据目录下：
```text
%LocalAppData%\NoFences\
```
- 分区元数据：`%LocalAppData%\NoFences\<分区 GUID>\__fence_metadata.xml`
- 托管中的桌面快捷方式：`%LocalAppData%\NoFences\<分区 GUID>\items\`
- 全局主题配置文件：`%LocalAppData%\NoFences\__theme_settings.xml`

### 自动保护与手动恢复
1. **防覆盖机制**：恢复桌面快捷方式时，若桌面上已存在同名文件，程序不会盲目覆盖，确保用户数据安全。
2. **退出自动恢复**：正常退出 NoFences 时，托管的所有桌面快捷方式会自动还原到桌面原本的网格位置。
3. **故障恢复命令行**：如果系统遇到断电或异常崩溃导致桌面快捷方式尚未恢复，只需在退出 NoFences 后执行以下命令即可一键永久释放并恢复所有受托管的桌面快捷方式：
   ```powershell
   NoFences.exe --restore-shortcuts
   ```
   （静默运行模式可添加 `--silent` 参数：`NoFences.exe --restore-shortcuts --silent`）

## 💻 系统要求

- **操作系统**：Windows 10 1607（Build 14393）或更高版本（深度适配 Windows 11）
- **架构**：x64 或支持 x64 应用兼容层的 Windows 设备
- **运行时**：.NET Framework 4.8

## 🛠️ 从源码构建

本项目采用原生 WinForms 与 x64 平台目标，仅支持 Visual Studio / MSBuild 编译，**不支持** `dotnet CLI`：

```powershell
msbuild NoFences.sln /p:Configuration=Release
```

- **编译输出路径**：`NoFences\bin\Release\NoFences.exe`
- **目标平台**：x64
- **目标框架**：.NET Framework 4.8
